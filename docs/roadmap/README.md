# KSC Public Record Intelligence — Roadmap Package

Copy the `docs/roadmap/` folder into the project repository.

Start with `docs/roadmap/00_MASTER_ROADMAP.md`.

The package contains the original 13-phase core roadmap, the added Phase 5B visual-parity remediation milestone, and Phase 14 as the post-core external-media/public-statements feature.

Use `AGENT_PHASE_USAGE.md` for short prompts to Claude Code or Codex instead of pasting giant instructions.

Important: repository code, migrations, tests, Git state, `DECISIONS.md`, `PROJECT_STATE.md`, and `MEMORY.md` remain more authoritative than these roadmap files if anything becomes stale.
